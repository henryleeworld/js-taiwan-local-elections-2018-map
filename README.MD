# JS 2018 年中華民國直轄市議員及縣市議員選舉選舉區投票結果地圖

2018 年直轄市暨縣市議員選舉共選出 912 席的議員席次，其中國民黨囊括 394 席，民進黨囊括 238 席，佔所有席次近七成（69.30％），若再加上無黨籍及未經政黨推薦者所獲得的 234 席，其他所有小黨的席次加總，也只拿到 46 席，僅佔總席次的 5％；若再扣掉立院第三大黨時代力量所獲得的 16 席，更僅剩 30 席。
